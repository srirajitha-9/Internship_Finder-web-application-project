# Internship_Finder-web-application-project


Internship Finder is a web-based application developed to help students find internship opportunities related to their field of study and skills. The platform provides a centralized system where students can create profiles, browse internships, and apply directly, while companies can post internship opportunities and review student applications.

This project was developed as a mini project for the Software Engineering program under the Faculty of Computing and Technology.

Features
Student Module
Student registration and login
Create and update student profiles
Add skills and qualifications
Browse internships by category
Apply for internships
View application status

Company Module
Company registration and login
Post internship opportunities
View student applications
Review student profiles, skills, and qualifications

Security Features
Password hashing using PHP
Session-based authentication
Role-based access control

Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: Apache (XAMPP)

System Objectives
Match students with internships based on category and skills
Simplify internship management for students and companies
Provide a centralized internship platform
Improve efficiency in the internship application process

Database Tables
Students
Companies
Internships
Applications

Future Enhancements
Resume/CV upload feature
Push notifications
Mobile application support
Interview scheduling system

Project Outcome

The system successfully improves internship searching and management by providing relevant internship matching, organized application handling, and better communication between students and companies.
